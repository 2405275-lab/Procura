# Changelog

All notable changes to the Procura procurement workspace are documented in this file.

## [1.0.0] - 2026-08-05
- **Initial Release**: Full-stack multi-agent procurement suite.
- **AI Agent Pipelines**: OCR, Extraction, Policy, scoring, and Purchase Order agents integration.
- **Database Schema**: SQLite file structures and PostgreSQL seeding.
- **Aesthetic Portals**: Dark mode controls, help center FAQ lists, and system resource monitors.
